# Basement PPL

A 3-day Push / Pull / Legs plan for a home gym (dumbbells to 30 lb, a 36 lb kettlebell, bands, a bench), built as an installable web app with set logging, an automatic rest timer, progression hints, and start/finish form photos.

**Open it:** https://sniderjake.github.io/basement-ppl/

## Install on a phone
- **iPhone (Safari):** open the link → Share → *Add to Home Screen*.
- **Android (Chrome):** open the link → ⋮ menu → *Install app* (or *Add to Home screen*).

Open it once while online; after that it works with no signal.

## Your data
Workouts are saved on the phone only (browser storage). Nothing is uploaded. Use **Log → Copy backup** now and then and keep the text somewhere safe; **Restore** puts it back.

## Updating
After changing any file, bump `VERSION` in `sw.js` so installed copies refresh.
